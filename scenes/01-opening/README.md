# 星月夜开场

当前唯一视频为 `星月夜-树影修正与月晕分速-5秒-4K-v007.mp4`（4K、24fps、5秒）。`starry-v007-poster.jpg` 是从该视频提取的首帧，用于加载和播放失败时的静态底图。

## 粒子显示与恢复

- HTTP/HTTPS 下优先使用 `01-opening.js` 的原有 WebGL 粒子。视频显示保留 4K，粒子采样纹理最长边限制为 1920，按解码帧更新。
- 直接双击 HTML 时使用 `opening-fallback.js` 的 Canvas 2D 粒子。通过绘制视频后应用圆点遮罩实现，不读取像素、不绕过浏览器跨域限制。
- GPU 上下文丢失时立即接替为 2D 粒子，恢复后重建着色器、纹理、缓冲区和 uniform，在真正画出一帧后切回 WebGL。
- `pagehide.persisted=true` 只暂停，保留 GPU 资源；真正离开时释放，后续 `pageshow` 会在需要时重建。后台暂停后返回也会恢复。
- 暂时纹理上传错误最多重试三次；期间持续显示备用粒子。视频再次可用、页面激活或返回前台时允许重试。安全限制改用 2D，不反复尝试被浏览器禁止的上传。
- 视频失败时用新视频的封面生成粒子。Canvas 或脚本不可用时，HTML 中独立的 CSS 静态粒子仍显示。
- “减少动态效果”停止动画，但保留静态粒子，不再隐藏整层。
- 外部 Tailwind 脚本延迟加载，开场自己的 CSS 和脚本无需等待外部 CDN。

备用 2D 模式保留视频颜色与离散点外观，但不会执行 WebGL 的逐粒子鼠标涡旋。CSS 最后一级是静态装饰粒子。浏览器关闭页面、禁用样式、无法读取整个网站等情况无法由网页保证显示。

## 验证

安装或提供 `playwright` 和 `pngjs` 后，在项目根目录运行：

```powershell
node scenes/01-opening/opening-browser.test.cjs http://127.0.0.1:8766 chrome
node scenes/01-opening/opening-browser.test.cjs http://127.0.0.1:8766 msedge
```

需要对应 Chrome / Edge 和一个服务项目根目录的 HTTP 预览服务器；端口可通过参数更换。`STARRY_TEST_OUTPUT` 指定截图与 JSON 报告目录，默认使用系统临时目录。

测试覆盖 HTTP、file://、刷新、场景切换、连续上下文恢复、缓存生命周期事件、模拟后台返回、WebGL 缺失、着色器错误、暂时/持续/安全纹理错误、视频/封面缺失、Canvas 缺失、减少动态效果、窄屏旋转、自动播放被拒绝、缺少视频帧回调以及关闭 JavaScript。缓存返回使用 persisted 生命周期事件模拟，不等同于所有浏览器真实后退缓存命中的测试。

除了状态检查，还读取真实 GPU 绘制像素，并对比显示/隐藏粒子层的截图，以发现空画布或未显示的粒子。测试隔离与开场无关的远端 CDN 和作品集素材。
